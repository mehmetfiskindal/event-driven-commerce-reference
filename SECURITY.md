# Security Policy

## Scope

This repository is a demo and portfolio project. It is not intended for production deployment and does not claim production-grade hardening.

That said:

* do not commit secrets
* do not commit real credentials
* do not open issues containing sensitive data

## Reporting

If you notice a security issue in the code or documentation, please report it privately to the repository owner rather than posting exploit details publicly first.

## Expectations

Because this is not a live product:

* examples may use local-only demo credentials such as `test`
* infrastructure is designed for local development with LocalStack
* security, compliance, and operational guarantees are out of scope unless explicitly implemented and documented

If you reuse any part of this repository in a real system, you are responsible for a full security review.
